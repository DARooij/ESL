# README

We did not actually finish getting the demo to work, so while there are instructions for compiling the code, it likely will not work correctly (or at all). Controller.cpp contains the controller class whose run() function performs homing and basic controller, without any vision.

## Project structure

The project is structured as following:

`/FullController/` directory contains the exported c++ 20-sim model, with `FullController.cpp` being the main source file.

`/VidPip.cpp` is the main source file to build from, it contains the gstreamer application as well as a thread 

`/Controller.cpp` is the main source file for the controller, it contains a run function which is the loop for controller

`/object_tracker.cpp` is the main source file for the opencv code, it is called from the gstreamer application and processes the frame to output the normalized x and y values in a std::tuple

`/soc_system.h` is the header file generated by quartus needed for using the Avalon bus

## Compiling

To compile the project run the following command:

`g++ VidPip.cpp object_tracker.cpp Controller.cpp FullController/*.cpp FullController/common/*.cpp -o VidPip $(pkg-config --cflags --libs gstreamer-1.0 opencv4)`

Obviously, this requires gstreamer-1.0 and opencv, as the installation process for this is distro depended no instructions for this are given, we did not try to build this on windows.

After compilation the program can be run using VidPip. 

We commented out a videosink which we used for testing the opencv output, it's still there for testing.
